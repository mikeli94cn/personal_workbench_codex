# Character stickers

Created with the built-in image generation tool for this workbench. Each asset is a separate transparent chibi character illustration; no external image requests are needed at runtime.

Files: `sakura.png`, `kero.png`, `spinel.png`.

Shared prompt:

> Use case: stylized-concept. Asset type: tiny transparent UI character sticker for a personal task calendar. Subject: [character below]. Style: polished cute chibi anime sticker, rounded silhouette, clean dark outlines, soft pastel shading, charming expressive face, consistent white sticker edge. Composition: one character only, centered square, entire head and upper body visible, no cropping, character fills 85% of square, optimized for recognition at 32–48px. Background: genuinely transparent. No text, lettering, watermark, scene, extra characters or drop shadow.

Character subjects:

- Sakura Kinomoto from Cardcaptor Sakura: short chestnut bob haircut, green eyes, pink magical-girl hat and tiny white wings, smiling, holding a little pink star wand.
- Kero-chan (Keroberos in his small mascot form) from Cardcaptor Sakura: small golden yellow teddy-bear-like creature, large round ears, white feather wings, cheerful open smile.
- Spinel Sun (Suppi in his small mascot form) from Cardcaptor Sakura: small dark navy-blue cat-like creature with large ears, tiny blue butterfly wings, blue eyes and a gentle slightly reserved expression.

The stickers are decorative; button labels remain the source of accessible names. CSS hover tilts are disabled under `prefers-reduced-motion: reduce`.
